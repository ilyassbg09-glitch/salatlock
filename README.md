# Salat Lock 🕌

Application Android qui bloque le téléphone à l'heure de la prière.
Pour débloquer : faire ses ablutions, scanner un lavabo, puis prier pendant le compte à rebours.

**Télécharger : https://ilyassbg09-glitch.github.io/salatlock**

Gratuit · sans pub · sans pistage · fonctionne sans internet.

Voir `LISEZMOI.md` pour recompiler.
